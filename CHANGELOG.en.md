# Changelog

[日本語](CHANGELOG.md)

## [v2026.10.18](https://github.com/nagataaaas/wots4-debugger/releases/tag/v2026.10.18)

- Added the hitch log (`jank`). It finds frames that took longer than usual and writes what the game did during them to `logs/`. Off by default.
- Added the voice log (`voice_trace`). Each time a character voice is played, it writes to `logs/` whether it played and, if not, why. Off by default.

## [v2026.10.14](https://github.com/nagataaaas/wots4-debugger/releases/tag/v2026.10.14)
